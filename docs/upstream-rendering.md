# Native Go Space Age renderer

The update is based on [FactorioMapWebUI](https://github.com/FactoryGameFan/FactorioMapWebUI), pinned at [`562e015405bd1b68ffb4dd72ec0d2befa5474540`](https://github.com/FactoryGameFan/FactorioMapWebUI/tree/562e015405bd1b68ffb4dd72ec0d2befa5474540) (2026-10-25). The reference implementation and its measured noise documentation informed these Go ports; no upstream executable or runtime is invoked. The browser requests PNG tiles from Go. Gleba also renders in Go; its additional 2.1.23 implementation and fresh oracle checks are documented in [gleba-rendering.md](gleba-rendering.md).

## Implementation

- `factorio_noise32.go` and `factorio_gradient32.go`: single-precision operation boundaries, recovered 256-entry gradient table, point/grid basis behavior, multioctave offsets, quick/amplitude noise, and starting cones.
- `factorio_voronoi.go`: seeded jitter, distance metrics, facets, and pyramids. Sampling is immutable with a bounded stack search.
- `factorio_fulgora.go`: cells, warped elevation, oil ocean, natural terrain, roads, ruins, tile competition, and scrap probability.
- `factorio_aquilo.go`: resource islands, Voronoi ice terrain, nine tile probabilities, wells, and iceberg probability.
- `factorio_vulcanus_resources.go` plus `factorio_vulcanus.go`: starting resource cones, regional patches, and their effects on lava, cracks, jagged ground, and sulfur soil.

Resource-region caches are bounded and mutex-protected for shared tile workers. Nauvis keeps its existing noise kernels. The subsequent [Factorio 2.1.23 accuracy pass](factorio-2.1-accuracy.md) independently checks the installed game data and binary, adding shared cliff geometry, Gleba feature fields, native candidate streams and chart rendering across all five planets. Real entity boxes, integer alpha accumulation, ore checkerboard phase and reverse draw order are covered by a separate controlled PNG oracle. This is not a port of upstream's complete entity placement system. Enemy placement, some cliff/resource details, broad zooms, demolisher territories and arbitrary mod expressions remain partly or wholly approximate; the accuracy report records those limits separately from terrain parity.

## Validation

The upstream terrain PNG fixtures are generated by Factorio at map seed `123456`, 1024×1024, centered at `(0, 0)`, one tile per pixel, with entity layers disabled. Space Age seeds include CRC32(surface name). Vulcanus and Aquilo resource sizes are zero in these captures; starting cones can still affect terrain with those controls. Point-field fixtures force the surface seed to `123456` instead and use the point evaluator. These two evaluation paths have intentionally different float32 rounding.

| Surface | Different terrain pixels / 1,048,576 | Regression ceiling |
| --- | ---: | ---: |
| Nauvis | 10 | 10 |
| Vulcanus | 1 | 1 |
| Fulgora | 20 | 20 |
| Aquilo | 0 | 0 |
| Gleba | 0 | 0 |

Fulgora's sampled cell, elevation, and scrap fields and Aquilo's 1,024 sampled elevation/aux fields agree exactly with their fixture values. The separate generated-world Fulgora tile fixture agrees at 4,915/5,057 locations after normalizing the ocean `-2` variants. Factorio's generated-world tile correction differs from preview tile scoring. The older local Vulcanus tile-name fixture agrees at 374/381. These measurements cover the captured seeds/settings and do not establish all-seed or entity parity.
